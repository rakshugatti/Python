1. os and shutil Modules
os module:-
Provides functions to interact with the operating system.
Common uses:

1)os.listdir() → list files and folders
2)os.path → manipulate file/folder paths
3)os.makedirs() → create directories
4)os.rename() → rename files
5)os.walk() → traverse directories recursively
6)os.remove() / os.rmdir() → delete files/folders

shutil module:-
High-level file operations.
Common uses:
•shutil.move() → move files/folders
•shutil.copy() → copy files
•shutil.rmtree() → delete folder tree
•shutil.disk_usage() → get disk usage
•shutil.copytree() → copy entire folder structure
