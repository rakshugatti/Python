(a) Method Overriding

Explanation:
Method overriding occurs when a child class provides its own implementation of a method that already exists in the parent class.

(b) Duck Typing

Explanation:
Duck typing means Python does not care about object type; it only cares whether the object has the required method.

"If it quacks like a duck, treat it like a duck.

(c) Operator Overloading

Explanation:
Operator overloading allows *operators like +, -, , etc. to work with objects using special methods.

(d) Method Overloading using Default Arguments and *args

Python does not support true method overloading, but it can be achieved using *default arguments or args.
