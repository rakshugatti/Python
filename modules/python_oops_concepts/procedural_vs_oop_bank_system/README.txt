Project: Procedural vs Object-Oriented Programming (Bank System)

This project compares Procedural Programming and Object-Oriented Programming using a simple bank account example.

Files Included:
1. procedural_bank.py – Bank system using functions
2. oop_bank.py – Bank system using classes and objects
3. bank_comparison.py – Demonstrates both approaches

Concepts Demonstrated:
- Functions
- Classes and Objects
- Data organization
- Code reusability

Advantages of OOP:
1. Better code organization
2. Data security through encapsulation
3. Reusable and scalable code
4. Easier maintenance for large applications

Comparison of Procedural Programming and Object-Oriented Programming
Procedural Programming

Procedural programming is a programming paradigm where the program is organized as a sequence of functions or procedures. The data and functions are separate, and functions operate on the data.

Example languages: C, Pascal

Object-Oriented Programming (OOP)

Object-Oriented Programming organizes programs using classes and objects. Data and methods that operate on the data are combined into a single unit called a class.

Example languages: Python, Java, C++
