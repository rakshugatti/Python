Four Pillars of Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) is based on four main principles: Encapsulation, Abstraction, Inheritance, and Polymorphism. These concepts help in writing modular, reusable, and maintainable programs.

1. Encapsulation
Definition

Encapsulation means wrapping data and methods together in a class and restricting direct access to the data.

Real-world analogy

A capsule medicine hides its internal ingredients. Users only interact with the capsule, not the internal contents.

2. Abstraction
Definition

Abstraction means hiding implementation details and showing only essential features to the user.

Real-world analogy

When driving a car, we use the steering wheel and pedals without knowing the internal engine mechanism.

3. Inheritance
Definition

Inheritance allows a child class to acquire properties and methods of a parent class.

Real-world analogy

A child inherits characteristics from parents, such as eye color or height.

4. Polymorphism
Definition

Polymorphism means the same method name can perform different actions depending on the object.

Real-world analogy

A person behaves differently as a teacher, parent, or friend depending on the role.
