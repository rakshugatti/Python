Concepts in Object-Oriented Programming
1. Class

A class is a blueprint or template used to create objects. It defines the attributes (variables) and methods (functions) that the objects will have.

Example:
A Car class defines properties like brand, model, year, and speed.

2. Object

An object is an instance of a class. Each object has its own data and can use the methods defined in the class.

Example:
car1, car2, and car3 are objects created from the Car class.

3. Attributes

Attributes are variables inside a class that store information about an object.

Example attributes for a car:

brand

model

year

speed

4. Methods

Methods are functions defined inside a class that perform actions using the object's attributes.

Example methods:

accelerate() → increases speed

brake() → decreases speed

display_info() → displays car details
